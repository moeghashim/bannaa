An agent project begins with a task worth completing. Before choosing tools or coordinating several agents, describe what a successful result looks like.

## Define the job

Write down the inputs, the expected output, and the boundaries. A narrow task is easier to test and improve.

## Test more than the happy path

Try missing information, conflicting instructions, and failed tool calls. Record the result and decide when the agent should stop or ask for help.

## Add coordination when it helps

Compare a multi-agent approach with your single-agent baseline. Keep the added complexity only when it produces a useful improvement in quality, speed, or cost.
